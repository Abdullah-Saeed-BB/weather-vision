<h1>Weather Vision</h1>

Our project aimed to address the increasing risk of flash floods in urban areas, so we developed an application that uses satellite data and an AI model to predict potential flood risks.

This project was developed as part of our participation in the [NASA Space Apps Challenge hackathon](https://www.spaceappschallenge.org/nasa-space-apps-2024/find-a-team/weather-vision/).
#### [Live demo](https://weather-vision-iota.vercel.app/)
